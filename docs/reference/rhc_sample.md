# Cleaned RHC Benchmark Cohort

The cleaned Right Heart Catheterization (RHC) cohort from the SUPPORT
study, as produced by
[`prepare_rhc_data`](https://mostafa-abbas.github.io/IndepAssoc/reference/prepare_rhc_data.md).
RHC was associated with harm in the original analysis (Connors et al.
1996); the data are bundled so the validation vignette and tests run
offline and deterministically.

## Usage

``` r
rhc_sample
```

## Format

A list with two elements:

- data:

  A data frame with 5735 rows and 63 columns. `swang1` is the binary
  exposure (1 = RHC); `dth30` is 30-day mortality and `los` is length of
  stay in days.

- covariates:

  A character vector of the 50 confounder column names used by the
  adjustment methods.

## Details

The raw file's quirks are resolved here: the `write.csv` row-names
column is dropped, the `cat2` category "None" (stored as the literal
text `"NA"`) is restored, remaining literal `"NA"` strings become real
missing values, the `swang1` exposure and `dth30`/`death` outcomes are
recoded 0/1, and `los` is derived from the admission and discharge
dates. The heavy-missingness columns `adld3p` and `urin1` are excluded
from the covariate vector.
